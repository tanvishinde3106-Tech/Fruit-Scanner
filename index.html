Smart Fruit Safety Scanner

Project Introduction & Understanding: An advanced embedded ESP32 two-probe system engineered for non-destructive and sample-based evaluation of fruit freshness, ripeness, internal pH, and chemical residue screening. Designed to ensure food safety and quality automation for agricultural logistics and consumers.

Engineering Highlights of the Model:

The physical prototype integrates a custom 3D-printed handheld casing housing the ESP32 microcontroller, dual peristaltic pumps for the injection and collection probes, an AS7265x optical sensor module aligned with a quartz sample window, and an independent Li-ion power regulation circuit.

Internal Hardware Setup — Sensors Used in This Analysis

The following modular hardware architecture powers the dual-probe ESP32 scanner device:

OLED Display (0.96")SDA → GPIO21 · SCL → GPIO22 (I²C)
AS7265x NIR / Multispectral SensorSDA → GPIO21 · SCL → GPIO22 (I²C) — 18 channels
TCS34725 Colour SensorSDA → GPIO21 · SCL → GPIO22 (I²C) — R, G, B, C
UV Sensor — GUVA-S12SDAOUT → GPIO34 (ADC)
MQ-3 Gas SensorAOUT → GPIO35 (ADC)
MQ-135 Gas SensorAOUT → GPIO36 (ADC)
DS18B20 Temperature SensorDQ → GPIO4 (1-Wire)
pH Sensor (with sample)AOUT → GPIO32 (through ADC)
Load Cell + HX711DT → GPIO18 · SCK → GPIO19
Scan ButtonGPIO27
Two-Probe SystemProbe 1 = injection · Probe 2 = collection (DC pump + valve control)
ESP32 Microcontroller + Battery (3.7V Li-ion)Main controller, filtering, normalising, model "Fruit-Quality-V1"
